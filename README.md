# Selection-bias-and-heterogeneity

This repository contains the R code used to conduct the simulation study of the paper "Selection without Collider Stratification can Bias Instrumental Variable Analyses in the Presence of Causal Effect Heterogeneity". The following files are included:
1) "SBaH_Functions.R": R functions used to generate data and implement instrumental variable analysis.
2) "SBaH_Final_Simulation.R": Code used to run the simulation study in the main part of the paper.
3) "SBaH_Final_Analysis.R": Code used to analyze the results and summarize them in tables.
4) "SBaH_Asymptotic.R": An implementaton of the simulation study with large sample size (table S4 of the paper).

The results can be found in the corresponding ".RData" files in the Results folder.
